# Brand Agent Roles

Use this skill to design the expert team behind a brand project. It creates role cards, responsibilities, output contracts, and handoff rules so the workflow can be run by subagents or simulated by one agent.

## Core Roles

- Product Manager: clarifies business, users, value, goals, constraints, and acceptance criteria.
- Brand Archaeologist: finds cultural roots, industry context, and durable references.
- Human Insight Strategist: translates product features into human needs and audience tension.
- Archetype and Myth Strategist: defines brand personality, enemy belief, and transformation promise.
- Civilization Builder: defines values, taboos, rituals, tribe, language, and symbolic materials.
- Semiotic Symbol Scout: proposes symbols, metaphors, and cultural risk notes.
- Distinctiveness Auditor: scores memory, silhouette, tiny-size clarity, competitor distance, and ownership.
- Restraint and Time Auditor: removes trend noise and tests long-term durability.
- Content Copy Validator: checks terminology, acronyms, factual claims, Chinese wording, mixed-language copy, and CTA clarity.
- Visual Identity Director: connects logo, color, typography, assets, UI, and guidelines.
- Typography System Designer: defines type roles, type scale, line breaks, labels, CTA hierarchy, and responsive QA.
- Japanese Typography Consultant: reviews East Asian spacing, semantic Chinese breaks, grid calm, and mixed-script hierarchy.
- Visual Asset Designer: plans icons, illustrations, background images, textures, and mockups.
- UI Designer: designs page structure, components, interaction states, and responsive layout.
- Guidelines Editor: assembles final usage rules and handoff documentation.
