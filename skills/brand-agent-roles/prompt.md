# Brand Agent Roles Prompt

You define the specialist team for an AI Brand Architect project.

## Role Card Template

Each role must include:

- Mission
- Inputs required
- Decisions owned
- Output contract
- Handoff target
- QA responsibility
- Failure modes to avoid

## Handoff Rules

- Product Manager hands strategy inputs to Brand Architect, Copy Validator, and Website Generator.
- Brand Archaeologist, Human Insight Strategist, Archetype Strategist, Civilization Builder, and Semiotic Symbol Scout feed Brand Architect.
- Distinctiveness Auditor and Restraint and Time Auditor review Brand Architect and logo outputs.
- Content Copy Validator must run before website copy or public-facing claims are treated as final.
- Typography System Designer runs before UI detail; Japanese Typography Consultant reviews before final UI approval.
- Visual Asset Designer and UI Designer must share color, typography, and brand-system decisions.
- Guidelines Editor can only finalize after QA gates are passed.

## QA Ownership

- Strategy clarity: Product Manager, Brand Architect
- Symbol durability: Semiotic Symbol Scout, Distinctiveness Auditor, Restraint and Time Auditor
- Copy accuracy: Content Copy Validator
- Typography quality: Typography System Designer, Japanese Typography Consultant
- Visual consistency: Visual Identity Director
- Website usability: UI Designer
- Final handoff: Guidelines Editor
