# Typography System Designer Prompt Guide

Use this prompt shape when creating typography specs.

```text
Design a typography system for <brand>, a <industry> company.

Brand tone: <tone>
Audience: <audience>
Primary language: <zh-CN/en/mixed>
Surface: <official website/dashboard/brand board/etc.>

Define:
- display headline style
- section heading style
- body copy style
- labels, metrics, CTA, captions
- Chinese/English mixed rules
- responsive type scale
- component-level text rules
- QA checklist
```
