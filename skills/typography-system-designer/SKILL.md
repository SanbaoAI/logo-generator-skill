# Typography System Designer

Use this skill before UI design whenever text is a major part of the page. The goal is to make the company feel clear, premium, readable, and intentional through type, not just colors and layout.

## Role In The Workflow

Run typography after Brand Design and Color Design, before Visual Asset Design and UI Design:

```text
PM Brief
-> Design Director
-> Brand Design
-> Color Design
-> Typography Design
-> Visual Assets
-> UI Design
-> Director Review
```

## Typography Responsibilities

Define:

- Font role strategy: display, heading, body, label, numeric, code/console.
- Chinese/English mixed typesetting rules.
- Type scale for desktop, tablet, and mobile.
- Line-height, paragraph width, and section rhythm.
- Hero headline line breaks and emphasis.
- Navigation, CTA, caption, metric, and eyebrow hierarchy.
- Text density rules for cards, tables, dashboards, and console-like UI.
- Typographic QA checklist.

## Premium Tech Rules

For advanced AI, enterprise software, frontier tech, or engineering companies:

- Prefer confident sans-serif systems for product and interface credibility.
- Use serif type only when it supports brand heritage or editorial gravitas; do not let it make the page feel old or academic.
- Make the hero headline large but controlled. Prevent long Chinese/English mixes from colliding with adjacent visuals.
- Use short English labels for system surfaces, but make primary user value clear in Chinese when the audience is Chinese.
- Keep labels compact and uppercase only when they remain legible; letter spacing must be 0 unless the implementation environment explicitly allows otherwise.
- Use numeric and console text as structured information, not decoration.
- Avoid tiny low-contrast copy inside dark panels.
- Use fewer type styles with stronger contrast rather than many similar sizes.

## Required Outputs

Return:

- `Typography Strategy`
- `Font Role System`
- `Type Scale`
- `Mixed Chinese-English Rules`
- `Hero Typography`
- `Component Typography`
- `Responsive Typography`
- `Typography QA`

## QA Checklist

Before final delivery, verify:

- The hero headline fits beside its visual on desktop.
- Mobile line breaks feel intentional and do not create orphaned words.
- Body copy has readable line length.
- Labels, captions, and CTAs remain legible at small sizes.
- Chinese and English text do not feel like two unrelated systems.
- The type style supports the brand tone and industry.
- Text hierarchy makes the page scannable in 5 seconds.
